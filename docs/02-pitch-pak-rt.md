## Ringkasan 30 Detik

Saya, Zulmi, warga RT 003, mengembangkan aplikasi **Guyub** untuk
mempermudah pengelolaan data warga, kas RT, pengumuman, dan surat
pengantar. Aplikasi ini hasil pengembangan dari tugas akhir kuliah saya
yang saya lanjutkan menjadi produk siap pakai.

**Permintaan saya:** izin Bapak untuk menjadikan RT kita sebagai **pilot
pertama** (uji coba), gratis selama 6 bulan. Sebagai gantinya, saya minta
masukan Bapak, Bendahara, dan Sekretaris untuk perbaikan aplikasi.

**Jika tidak cocok setelah 1 bulan**, saya akan hentikan, dan Bapak
kembali ke cara manual. Tidak ada biaya, tidak ada resiko.

## Masalah yang Saya Lihat di RT Kita

Dari pengamatan dan obrolan dengan Bapak selama ini:

1. **Data warga di buku tulis** — rawan salah tulis, susah dicari, bisa
   hilang atau rusak kalau buku ketinggalan/basah
2. **Kas RT dicatat manual** — Bendahara harus rekap dari nol tiap akhir
   bulan, rawan salah hitung saat lapor ke Pak RW
3. **Pengumuman di mading** — tidak semua warga lewat mading, sering ada
   yang tidak tahu informasi penting (kerja bakti, jadwal ronda)
4. **Surat pengantar butuh waktu** — warga harus datang ke rumah Bapak,
   tunggu ditulis manual, baru TTD. Apalagi kalau Bapak sedang bekerja

## Solusi: Aplikasi Guyub

Satu aplikasi yang bisa:

| Fitur | Manfaat |
|---|---|
| **Data Warga Digital** | Input sekali, cari dalam 2 detik. Otomatis update umur |
| **Kas RT Otomatis** | Bendahara input dari HP, laporan PDF otomatis tiap bulan |
| **Pengumuman via WhatsApp** | Broadcast ke semua warga langsung ke WA mereka |
| **Surat Pengantar Digital** | Warga request dari HP, Bapak approve dari HP, surat langsung jadi PDF |
| **Jadwal Ronda** | Generate roster otomatis, reminder H-1 via WA ke yang giliran |

## Yang Tidak Perlu Dikhawatirkan

### "Saya belum lancar pakai HP"
Saya akan datang langsung ke rumah Bapak untuk **setup dan latihan
30 menit**. Kalau ada pertanyaan, bisa WhatsApp saya kapan saja.

### "Warga sepuh tidak bisa install app"
Tidak perlu install apa-apa. Warga dapat pengumuman, cek iuran, dan
request surat **semua lewat WhatsApp biasa**.

### "Data warga bisa bocor?"
Data disimpan di server yang terenkripsi. Hanya Bapak, Bendahara, dan
Sekretaris yang bisa akses data lengkap warga. Warga biasa hanya bisa
lihat data mereka sendiri. Aplikasi mengikuti **UU Perlindungan Data
Pribadi** yang berlaku sejak 2022.

### "Kalau aplikasinya error, RT kita gimana?"
Data warga dan keuangan **bisa di-download kapan saja dalam bentuk
Excel**. Walaupun aplikasi berhenti, data tetap jadi milik Bapak,
bukan milik saya.

### "Ini berbayar?"
Untuk pilot, **gratis 6 bulan penuh**. Setelah itu:
- RT di bawah 50 KK → **gratis selamanya** (RT kita kemungkinan fit)
- RT 50-100 KK → Rp 49.000/bulan (opsional, kalau butuh fitur tambahan)

## Yang Saya Berikan

1. **Akses penuh aplikasi gratis 6 bulan** untuk RT kita
2. **Setup + training langsung** di rumah Bapak (30 menit)
